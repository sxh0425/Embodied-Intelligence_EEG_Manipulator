# 第 05 课 · 朝向为什么是 9 个数

**目标**：让 warmup 第 5 级显示 ✅

---

## 1. 原理

一个物体的姿态要两样东西：**在哪** + **朝哪**。

- "在哪" → 3 个数就够：`[x, y, z]`
- "朝哪" → **3 个数不够**。所以用 3×3 = 9 个数。

为什么要 9 个？因为描述朝向的办法是：**把物体自己的三根轴（前后、左右、上下）分别说出来指向世界的哪个方向。** 每根轴 3 个数，三根轴就是 9 个数。

```
物体自己的 x 轴指向世界的 [0.71, 0.71, 0.00]
物体自己的 y 轴指向世界的 [0.71,-0.71, 0.00]
物体自己的 z 轴指向世界的 [0.00, 0.00,-1.00]

摆成 3 行 3 列：
[ 0.71  0.71  0.00 ]
[ 0.71 -0.71  0.00 ]
[ 0.00  0.00 -1.00 ]
```

这个 3×3 的表，就叫**旋转矩阵**，一般记作 `R`。

---

## 2. 那个"reshape 陷阱"

MuJoCo 在内存里**只留了一串 9 个数**，没有行列的概念：

```
data.xmat[编号]  →  [0.71, 0.71, 0.00, 0.71, -0.71, 0.00, 0.00, 0.00, -1.00]
```

9 个数，一字排开。所以你必须自己把它摆回 3 行 3 列：

```python
data.xmat[编号].reshape(3, 3)
```

摆成 3×3 之后才能当矩阵用。

**`.reshape()` 只是换个摆法，不改变数值。** 你不用记顺序规则，只需要知道"读朝向必须 reshape(3,3)"。

---

## 3. 这一课会用到的全部东西

| 写法 | 意思 |
|---|---|
| `data.xpos[编号]` | 位置，长度 3 |
| `data.xmat[编号]` | 朝向，长度 **9**（还是一串数） |
| `data.xmat[编号].reshape(3, 3)` | 朝向，变成 3×3 矩阵，可以用了 |
| 矩阵的用处 | `世界方向 = R @ 局部方向`（第 8 课细讲，先记着） |

```python
>>> R = data.xmat[h].reshape(3, 3)
>>> print(R)                         # 3 行 3 列
>>> print(R.shape)                   # (3, 3)
```
