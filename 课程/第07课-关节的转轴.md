# 第 07 课 · 关节的转轴

**目标**：让 warmup 第 7 级显示 ✅

---

## 1. 原理

门是怎么转的？绕着**合页**那根轴转。

机械臂的每个关节也一样：**每个关节都是绕着一根固定的轴在转。** 这根轴叫**转轴**。

描述一根轴，只需要一个方向。

```
关节 0 的转轴方向：[0, 0, 1]   ← 意思是"绕着竖直方向转"
```

（长度为 1 的向量叫单位向量，这里就是。方向是竖着的，z 轴方向。）

---

## 2. 关键：这个方向是哪里的方向？

这是本课最重要的一句话：

> **`model.jnt_axis[0]` 给的轴，是在"它挂着的那个 body 自己的坐标系"里，不是在世界的坐标系里。**

打个比方：一张地图上写着"向前走 100 米"。
- 如果你面朝北，"向前"= 往北
- 如果你面朝东，"向前"= 往东

**同样一句"向前"，因为你在转，实际结果就不同。**

`model.jnt_axis` 就是那句"向前"。它写死在模型里，永远不变。但每个 body 朝向不同，所以换算到世界里，结果完全不同。

**这一课你只需要拿到那个写死的值。下一课才把它换算到世界。**

---

## 3. 这一课会用到的全部东西

| 写法 | 意思 |
|---|---|
| `model.njnt` | 关节总数 |
| `model.jnt_axis[0]` | 第 0 号关节的转轴方向，长度 3 的数组，形状 `(3,)` |
| `model.jnt_type` | 每个关节是什么类型 |
| `mujoco.mjtJoint.mjJNT_HINGE` = 3 | 铰链关节（像合页，会转） |
| `mujoco.mjtJoint.mjJNT_SLIDE` = 2 | 滑动关节（像抽屉，会平移） |

Franka 这个模型：7 个手臂关节都是铰链（3），2 个手指关节是滑动（2）。
