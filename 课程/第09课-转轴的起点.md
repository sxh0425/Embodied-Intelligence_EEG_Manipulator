# 第 09 课 · 转轴的起点

**目标**：让 warmup 第 9 级显示 ✅

## 1. 原理：一条直线需要两样东西

第 8 课你拿到了转轴的**方向**。但一根轴（一条直线）光有方向还定不下来——**还得知道它经过哪个点。**

```
方向：竖直向上
经过点：(0, 0, 0.333)
```

这两样合起来，才能真正确定"轴在哪"。门也是一样：光知道合页是竖的没用，得知道合页装在哪。

## 2. 公式（和第 8 课结构一模一样）

第 8 课是**方向**的换算：

```
世界方向 = R @ 局部方向
```

这一课是**位置**的换算：

```
世界位置 = body的世界位置 + R @ 关节的局部位置
```

**为什么位置多了一个加法？**

- 方向是"往哪走"，跟你在哪无关 → 只乘
- 位置是"那个点在哪"，得先算出它离 body 有多远，再加上 body 自己在哪 → 先乘，再加

好记的说法：**"从 body 出发，按局部坐标走一段（R @ jnt_pos），就到关节了。"**

## 3. 这一课会用到的全部东西

| 零件 | 怎么拿 | 哪一课学的 |
|---|---|---|
| body 的世界位置 | `data.xpos[body编号]` | 第 04 课 |
| body 的旋转矩阵 | `data.xmat[body编号].reshape(3, 3)` | 第 05 课 |
| body 编号 | `model.jnt_bodyid[j]` | 第 06 课 |
| 关节在 body 内部的位置 | `model.jnt_pos[j]` | **本课新增** |

`model.jnt_pos[j]` 是一个长度 3 的数组，形状 `(3,)`——关节在"它挂着的那个 body 的坐标系里"的位置。

## 5. 一个会让人怀疑人生的坑

`model.jnt_pos[0]` 打印出来是 **`[0. 0. 0.]`**。

Franka 这个模型里，**所有**关节的 `jnt_pos` 都是 0。所以算下来：

```
A = data.xpos[body] + R @ [0,0,0] = data.xpos[body] + [0,0,0] = data.xpos[body]
```

也就是：**结果刚好等于 body 自己的位置。**

这不代表公式写错了，只代表"关节正好装在 body 的原点上"。换个模型（比如 UR5）`jnt_pos` 就不是 0 了，公式必须照写。

**写代码永远照公式写，别因为"这次答案碰巧一样"就省掉 `R @ jnt_pos`。**
