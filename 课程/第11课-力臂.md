**目标**：让 warmup 第 11 级显示 ✅（**过了这一关，EX5 就白送了**）

## 1. 原理：为什么需要力臂

你拧螺丝的时候，手握在螺丝刀中间 vs 握在末端，哪个省力？ **末端。**

因为力矩 = **力 × 力臂**。力臂越长，同样大的力产生的转动效果越大。

机械臂每个关节能出的力矩是固定的（电机决定的）。那"这个关节能让夹爪使多大劲"，就取决于**力臂**：

```
力臂 = 夹爪 到 这个关节的转轴 的垂直距离
```

夹爪离轴越远，力臂越大，这个关节的"杠杆"效果越强。

## 2. 你需要的所有零件，全都学过了

算"夹爪到第 j 号关节转轴的距离"，就是四个已知零件的组装：

| 需要 | 从哪来 | 哪一课 |
|---|---|---|
| 转轴经过的点 **A** | `data.xpos[body] + R @ model.jnt_pos[j]` | 第 09 课 |
| 转轴方向 **u** | `R @ model.jnt_axis[j]`，然后单位化 | 第 08 课 |
| 点 **P**（夹爪位置） | `data.xpos[mj_name2id(..., "hand")]` | 第 04 课 |
| 点到直线距离 | 三步公式 | 第 10 课 |

其中 `body = model.jnt_bodyid[j]`，`R = data.xmat[body].reshape(3, 3)`。

## 3. 组装（这是思路，不是让你直接抄走的完整答案）

```python
def 力臂(j):
    body = model.jnt_bodyid[j]
    R = data.xmat[body].reshape(3, 3)

    A = data.xpos[body] + R @ model.jnt_pos[j]   # 第 9 课
    u = R @ model.jnt_axis[j]                    # 第 8 课
    u = u / np.linalg.norm(u)                    # 第 10 课的单位化

    P = data.xpos[夹爪编号]                       # 第 4 课

    v = P - A                                    # 第 10 课
    proj = np.dot(v, u) * u
    return np.linalg.norm(v - proj)
```

**看出来了吗？这一课一个新东西都没有。** 它只是把前七课的成品接在一起。

这一课要练的能力是**组装**，不是学新 API。真正的难点在下一节。

## 4. 唯一的难点：所有写死的 0 都要换成 `joint_index`

第 8、9 课你写的是 `j = 0`。这一课函数有参数 `joint_index`，**每一处用到关节编号的地方都要换掉**：

```
model.jnt_bodyid[0]   ->   model.jnt_bodyid[joint_index]
model.jnt_pos[0]      ->   model.jnt_pos[joint_index]
model.jnt_axis[0]     ->   model.jnt_axis[joint_index]
```

这正是第 8 课结尾提醒你的坑：**当时图省事写死数字的人，这里会翻车。**
