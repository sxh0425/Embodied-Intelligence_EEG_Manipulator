## 1. 问题

> 有一个点 P。有一条直线，经过点 A、方向是 u。问：P 离这条直线有多远？

"有多远"指的是**垂直距离**——从 P 向直线作垂线，那条垂线的长度。

```
                     P
                     |
                     |  <-- 这个长度就是答案
                     |
   -----A------u-----+------------   <-- 直线
```

## 2. 思路：把 "P-A" 这个箭头拆成两半

先画一个从 A 指向 P 的箭头：

```
v = P - A
```

这个箭头可以拆成两半：

- **沿着直线方向的那一半**（叫投影 `proj`）—— 对距离没贡献
- **垂直于直线的那一半** —— 就是你要的答案

```
v  =  proj  +  垂直于直线的部分
                        ^ 这一段的长度就是答案
```

所以：**先算出 `proj`，用 `v` 减掉它，再量剩下的长度。**

## 3. 三个步骤（照抄成代码就行）

```python
# 第 1 步：把 u 变成单位向量（长度为 1）
u = u / np.linalg.norm(u)

# 第 2 步：算 v，以及 v 在 u 方向上的投影
v = P - A
proj = np.dot(v, u) * u

# 第 3 步：用 v 减掉投影，剩下的长度就是答案
return np.linalg.norm(v - proj)
```

**为什么要先单位化？** 因为简化公式 `proj = (v·u) * u` 只在 u 长度为 1 时成立。不单位化的话分母上得多除一个 `u·u`。先单位化更省事。

## 4. 这一课会用到的全部东西

| 写法 | 意思 |
|---|---|
| `np.linalg.norm(v)` | 向量 v 的长度（模），是一个数 |
| `np.dot(a, b)` | 两个向量的点积，是一个数 |
| `v / 数` | 向量每个元素都除以这个数 |
| `数 * 向量` | 向量每个元素都乘这个数 |
| `P - A` | 两个向量逐元素相减，还是一个向量 |

（`np` 就是 numpy：`import numpy as np`）

## 5. 手算验证（强烈建议做，这道题闭着眼也能验算）

取最简单的情况：直线是 **x 轴**（经过原点 `A=[0,0,0]`，方向 `u=[1,0,0]`），点 `P=[1, 1, 0]`。

肉眼可见：P 到 x 轴的距离应该是 **1**（就是它的 y 坐标）。

套公式：

```
u 已经是单位向量 -> 不用变
v = P - A = [1, 1, 0]
v·u = 1*1 + 1*0 + 0*0 = 1
proj = 1 * [1, 0, 0] = [1, 0, 0]
v - proj = [0, 1, 0]
长度 = 1     OK
```

在 Python 里敲一遍对一遍：

```python
>>> import numpy as np
>>> P = np.array([1.0, 1.0, 0.0])
>>> A = np.array([0.0, 0.0, 0.0])
>>> u = np.array([1.0, 0.0, 0.0])
>>> u = u / np.linalg.norm(u)
>>> v = P - A
>>> proj = np.dot(v, u) * u
>>> print(np.linalg.norm(v - proj))
```
