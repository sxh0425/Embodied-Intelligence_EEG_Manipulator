## 1. 原理

机械臂是一节一节接起来的：底座 → link1 → link2 → … → link7 → 夹爪。

**每个关节都不是悬空的，它长在某一节（body）上。** 关节的位置和朝向，都是相对"它长在的那一节"来说的。

所以想知道一个关节在哪，第一步是问：**你挂在谁身上？**

```
关节 0（名字叫 joint1） ──挂在──> body "link1"
关节 1（名字叫 joint2） ──挂在──> body "link2"
...
```

⚠️ **编号和名字差 1。** 关节编号 0 的名字叫 `joint1`。以后看到对不上号，先想想这个偏移。

---

## 2. 这一课会用到的全部东西

| 写法 | 意思 |
|---|---|
| `model.njnt` | 模型里关节总共有几个 |
| `model.jnt_bodyid[0]` | 第 0 号关节挂在哪个 body 上，返回 **body 编号**（是数字，不是名字） |
| `mujoco.mj_id2name(model, mujoco.mjtObj.mjOBJ_BODY, 编号)` | 数字编号 → 名字 |

注意最后那个：上一课是"名字 → 编号"（`mj_name2id`），这一课是"编号 → 名字"（`mj_id2name`）。**方向是反的，多了个 `2` 的位置不同**，别记混。
