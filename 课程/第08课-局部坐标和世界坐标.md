## 1. 两个坐标系

| 名字 | 跟着物体动吗 | 谁在用 |
|---|---|---|
| **局部坐标系** | 会跟着 body 一起转 | 模型文件里写死的那些数 |
| **世界坐标系** | 永远不动，整个场景的绝对参考 | 你要算的东西（夹爪在哪、离目标多远） |

上一课的 `[0, 0, 1]` 是**局部**的。你想知道机械臂到底绕哪个方向转，要的是**世界**的。

---

## 2. 换算公式（全部内容就这一条）

```
世界方向 = R @ 局部方向
```

`R` 就是那个 body 的旋转矩阵（第 05 课学过，3×3 那个）。

道理很简单：**"向前"这个方向要变成世界的方向，取决于你朝哪站。** `R` 就是"你朝哪站"。

---

## 3. 三个零件，全都在你手里了

| 零件 | 怎么拿 | 哪一课学的 |
|---|---|---|
| 局部方向 | `model.jnt_axis[j]` | 第 07 课 |
| 挂着的 body 编号 | `model.jnt_bodyid[j]` | 第 06 课 |
| 那个 body 的旋转矩阵 | `data.xmat[body编号].reshape(3, 3)` | 第 05 课 |

拼起来：

```python
j = 0
body = model.jnt_bodyid[j]
R = data.xmat[body].reshape(3, 3)
世界轴 = R @ model.jnt_axis[j]
```

四行。你每一行都认识。**这就是这一级为什么被标成"关键台阶"——它是第一次把前面学的零件组装起来。**

## 6. ⚠️ 一个坑：别被"看起来没变"骗了

第 0 号关节的 body 是 `link1`，而 `link1` 的朝向**正好是单位矩阵**（没转过的状态）。

所以：

```
第 7 级的答案：[0, 0, 1]
第 8 级的答案：[0, 0, 1]     ← 一模一样
```

**这不是你的代码错了，是运气。** 换成 `j = 1` 就会不一样。

所以别只看"数字对不对"，要看**代码是不是真的做了 R @ 那一步**。第 11 级要求你换关节，那时候写死的人会立刻翻车。
