# 第 5 课：这是具身智能吗？——传统控制 vs 具身智能

> 前置：第 1 课
> 本课回答：我一直在学的 FK/IK/雅可比，到底是不是具身智能？分界线在哪？

---

## 0. 你的直觉是对的

**你到目前为止学的一切 —— FK、雅可比、IK、关节控制 —— 100% 是传统控制（经典机器人学）。** 里面没有一丝"具身智能"。

这不是意外，也不是我写错了路径。但你有权知道**分界线在哪**，以及**为什么路径要从这一侧开始**。

而且这个困惑非常普遍：很多同学按教程学了一堆运动学，以为自己在学"具身智能"，其实学的是 1980 年代就成熟的东西。**你能主动发现这件事，说明你没在盲目跟练。**

## 1. 分界线到底在哪

一句话概括：

> **传统控制：人类工程师写公式。**
> **具身智能：神经网络从数据里拟合公式。**

展开成一张表：

| | 传统控制 / 经典机器人学 | 具身智能 / 机器人学习 |
|---|---|---|
| **谁决定"输入→输出"的映射** | 人类推导出**解析公式** | 神经网络从**数据**里拟合 |
| **输入是什么** | 精确的目标位姿、关节角 | 图像、点云、语言指令、人类演示 |
| **输出是什么** | 解析计算出的关节指令 | 网络推理出的动作 |
| **需要数据吗** | **不需要** | 需要（几百 ~ 几百万条） |
| **能处理没见过的东西吗** | 每个新物体都要重新建模 | 见过类似的就能试试 |
| **可解释性** | 强（能算出为什么） | 弱（黑箱） |
| **失败模式** | 数学上可预测 | 分布外（OOD）就崩 |
| **典型代表** | 产线上的焊接机械臂 | RT-2 / π0 / Diffusion Policy / ALOHA |

**核心区别不是"用不用机械臂"，而是"规则是谁写的"。**

## 2. 同一个任务，两种做法

任务：**抓起桌上的一个红色方块**。

### 传统控制的做法

```python
1. 相机标定，用颜色分割定位方块 → 得到它的精确位姿 (x, y, z, 姿态)
2. 因为已知它是正方体 → 手写规则"从正上方抓取"
3. 用 IK 解出对应的 7 个关节角
4. 规划一条直线轨迹
5. 位置控制执行
```

**⚠️ 换个蓝色圆柱体，第 2 步的规则就失效了。** 你得再写一套规则。

### 具身智能的做法

```python
1. 人类遥控演示 200 次抓取（各种物体）
2. 训练一个网络：输入 = 相机图像 → 输出 = 关节动作
3. 直接闭环执行
```

**⚠️ 换个没见过的物体，它可能也能抓 —— 但也可能突然崩，而且你说不出为什么。**

两个方案各有各的烂摊子。这就是这个领域的现状。

## 3. 但它们是**分层关系**，不是替代关系 ★ 最关键的一节

初学者容易以为"学了具身智能就不需要传统控制了"。**完全错误。**

看一下现在真实的具身智能系统的架构：

```
      「把可乐罐放到那只熊猫旁边」          ← 语言指令
                  │
                  ▼
        VLM / 大模型：理解语言 + 场景        ┐
                  │                        │  ← 这一层是「智能」
                  ▼                        │     神经网络干的
        目标物体 / 抓取位姿 / waypoint       ┘
                  │
                  ▼
        运动规划 + IK + 力控                ┐
                  │                        │  ← 这一层是「传统控制」
                  ▼                        │     你正在学的
         关节角度 / 力矩 → 电机             ┘
```

**上层策略输出的动作，最终还是要靠 IK 和位置控制才能变成可靠的物理行为。**

实际证据：

- **Diffusion Policy** 的真机实验，底层用的仍然是传统的笛卡尔阻抗控制器
- **大多数 VLA 论文**在 Franka 上做实验，底层是标准的关节位置控制
- **你几乎找不到**一个真实系统把传统控制层完全去掉
- 学术界有一句半开玩笑的话：**具身智能的代码里，70% 是传统控制**

**结论**：传统控制不是弯路，是**底层基础设施**。跳过它，上层就是空中楼阁。

## 4. 为什么这条路径要从传统控制开始

诚实的理由，不是场面话：

**① 没有底座，你无法调试**
学习型策略失效时，你要判断"是网络没学好"还是"运动学算错了"。如果运动学这块是黑箱，你永远分不清。

**② 传统部分有确定答案，学习部分没有**
FK 的对错可以验证到 1e-16。而"为什么这个策略成功率只有 40%"——可能调一周也找不到原因。**先用确定性知识建立信心和手感，再用不确定性知识攻坚。**

**③ 你的硬件决定的**
真正的具身智能核心（视觉策略训练、VLA 微调）**需要 GPU**。你这台 Intel Mac 跑不动。
但传统控制部分**可以完整跑完**（MuJoCo 是 CPU 的）。
所以：**用本机能做的部分打地基，等上云 GPU 时再做上层。** 这不是妥协，是合理的资源调度。

**④ 毕设答辩两个都要**
只有策略没有控制基础 → 工程上做不出可靠闭环。
只有控制没有策略 → 那不是"智能"，是自动化。

## 5. "具身智能"至少有四种含义 —— 你到底想做哪个

这个词被用得很乱。先明确你在追什么：

| 含义 | 在说什么 | 代表工作 | 和你的项目关系 |
|---|---|---|---|
| **① 机器人学习** | 用数据学"感知→动作"的映射 | Diffusion Policy、ACT | ★ 主战场 |
| **② VLA / 基础模型** | 视觉+语言→动作的大模型 | RT-2、OpenVLA、π0 | 了解 + 会微调 |
| **③ 仿真与 sim2real** | 大规模并行仿真 + 迁移到真机 | Isaac Lab、域随机化 | 你已在做（MuJoCo） |
| **④ 具身认知** | 认知科学视角：身体塑造智能 | 偏理论/心理 | 大概率不是你要的 |

**你的项目（EEG + 机械臂）最贴的是 ①**：

> EEG 作为一种**额外的感知模态**，解码出意图，作为策略的条件输入或高层目标。

这属于机器人学习里比较前沿的一个分支（多模态条件策略）。**所以你需要传统控制打底，但你的"智能"部分要做的是 ①。**

## 6. 地图：每个 Stage 属于哪一边

| Stage | 内容 | 属于 | 能不能提高"智能"成分 |
|---|---|---|---|
| 1 | 机器人学基础（FK/IK/雅可比） | 🔵 传统控制 | 不能，是地基 |
| 2 | MuJoCo 仿真 | 🔵 传统控制 | 不能，是工具 |
| 3 | 抓取与操作（规划、力控） | 🔵 传统控制 | 可以加一点（学习型抓取） |
| **4** | **模仿学习 / RL / VLA** | 🟢 **具身智能** | **这里才是** |
| 5 | EEG 解码 | 🟢 机器学习（非机械臂） | 是 |
| 6 | 融合闭环 | 🟢 具身智能 + 传统控制 | 是（共享自主） |
| **毕设** | EEG → 意图 → 机械臂 | 🟢 智能（意图层）+ 🔵 传统（执行层） | 两边都有 |

**你现在在 Stage 1，所以你觉得"这不是具身智能"——因为它确实不是。** 你在打地基。

**第一个真正的"具身智能时刻"在 Stage 4**：你写出一个神经网络，输入是**原始观测**，输出是**动作**，没有任何人写的规则——那一刻是你第一次碰到"智能"。

## 7. 加速路线：如果你等不及

上面是"稳"的路线。如果你更想早点摸到具身智能，可以这样压缩：

### 调整方案

| 原计划 | 加速版 | 省下的时间 |
|---|---|---|
| Stage 1 完整（含动力学、轨迹优化） | **只做 FK + 雅可比 + 数值 IK**，动力学了解概念即可 | 省 1–2 周 |
| Stage 2 MuJoCo 完整 | **只要能加载 + 能控制就行**，不求优雅 | 省 1 周 |
| Stage 3 抓取与操作 | **大幅压缩**，只做最简单的 pick-and-place | 省 2 周 |
| **Stage 4** | **提前，且优先做模仿学习（不是 RL）** | — |

### 加速版路线

```
Stage 1（精简）  FK + 雅可比 + 数值 IK
      ↓
Stage 2（精简）  MuJoCo 能加载能控制
      ↓
【提前插入】最小端到端模仿学习      ← 目标：让神经网络控制机械臂
      ↓
Stage 3（补）   需要时再回来补抓取和规划
      ↓
Stage 4（正式） 模仿学习 → RL → VLA
```

**关键原则**：先有一个"神经网络控制机械臂"的**能跑起来的最小例子**，哪怕任务极简单。理由：

> 建立正确的心理定位，比多学两周运动学重要得多。
> 你会明确知道"传统部分是在为什么服务"，学习动机完全不同。

### 但要注意的代价

完全跳过传统控制，你会在调策略时陷入这个困境：

> 策略成功率只有 30%。是网络的问题？是数据的问题？是 IK 算错了？是控制增益不对？还是抓取点选得不好？

**传统控制知识就是用来排除这些变量的。** 所以加速可以，但**别把地基完全跳过**——FK 和雅可比这两个一定要亲手写过。
