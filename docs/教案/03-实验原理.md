## 1. 实验 1：`qpos` 有多长

### 答案：9

### 底层原理

物理引擎要描述一个系统的"构型"（configuration），必须回答：**最少需要几个数字，才能完全确定它此刻的样子？**

- 空间中的一个点 → 3 个（x, y, z）
- 空间中的一个刚体 → 6 个（3 位置 + 3 朝向），但用四元数表示朝向要 4 个，所以内部是 7 个
- **Panda 机械臂 → 9 个**

为什么机械臂只要 9 个？因为**底座焊死在地上**。"它在哪、朝哪"是已知的常数，不需要变量。剩下的只有一个自由度来源：**关节**。

- 7 个手臂关节，每个是转动关节 → 各贡献 1 个角度
- 2 个手指关节 → 各贡献 1 个位移

```
qpos = [ j1, j2, j3, j4, j5, j6, j7, finger1, finger2 ]
         0   1   2   3   4   5   6     7        8
```

这就是 `model.nq = 9`。

> **术语**：这一组数字叫**广义坐标**（generalized coordinates）。"广义"是相对于"笛卡尔坐标"说的——它不限于 xyz 位置，任何能唯一确定系统构型的参数集合都叫广义坐标。

### 为什么必须挤成一个数组

因为引擎内部要解这样的矩阵方程：

$$M(q)\,\ddot{q} + C(q, \dot{q}) + G(q) = \tau$$

`M` 是质量矩阵，`q` 必须是一个向量，整个方程才能用线性代数的方法高效求解。这是数值仿真的通用做法。

### 一个容易误解的点

**`nu = 8` 而不是 9。** 执行器（电机）数量 ≠ 关节数量。两根手指被一个 equality 约束耦合，**一个电机带动两根手指**。

不要假设"一个关节一个电机"——这个假设会在你后面写控制代码时咬你一口。

## 2. 实验 2：转 joint1，末端高度会变吗

### 答案：不会变

### 底层原理：旋转矩阵

joint1 的转轴是 local 的 `[0, 0, 1]`，在这个构型下它恰好对齐世界的 **z 轴（竖直方向）**。

绕 z 轴旋转 θ 角的矩阵是：

$$
R_z(\theta) = \begin{bmatrix} \cos\theta & -\sin\theta & 0 \\ \sin\theta & \cos\theta & 0 \\ 0 & 0 & 1 \end{bmatrix}
$$

**看第三行 `[0, 0, 1]`**——这意味着 z 坐标经过变换后还是它自己。所以在数学上，绕 z 轴旋转**必然**保高度不变，这不是巧合，是矩阵结构决定的。

而 x、y 会按这个规律变：

$$
\begin{aligned} x' &= x\cos\theta - y\sin\theta \\ y' &= x\sin\theta + y\cos\theta \end{aligned}
$$

### 拿实测数据验算

末端初始位置 `(0.088, 0, 0.926)`，转 0.5 弧度后实测变成 `(0.0772, 0.0422, 0.9260)`。

```
x' = 0.088 × cos(0.5) - 0 × sin(0.5) = 0.088 × 0.8776 = 0.0772  ✓
y' = 0.088 × sin(0.5) + 0 × cos(0.5) = 0.088 × 0.4794 = 0.0422  ✓
z' = 0.926                                                       ✓
```

**完全吻合。** 这就是**正运动学（Forward Kinematics, FK）**：

> **给定所有关节角 → 算出末端位姿。**

`mj_forward` 做的就是这件事（外加算力、算接触）。

## 3. 实验 3：为什么有些连杆没动 ★ 最反直觉的一道

### 答案：只有 `link4`、`link7`、`hand`、两根手指动了

`link1`、`link2`、`link3`、`link5`、`link6` 的位置**没变**。

### 底层原理：转轴上的点不动

先纠正一个粗糙的说法：

> ⚠️ 「关节转的时候，它下游整棵子树跟着转」——这句话只对了一半。

**准确的表述是**：

> **关节转动时，它下游整棵子树确实都在转，但只有「不在转轴上的点」才会产生位移。落在转轴上的点，旋转后还在原地。**

把每个 body 的原点投影到水平面上，量一下它到 z 轴的距离：

| body | 世界坐标 | 到 z 轴距离 | 转 joint1 时 |
|---|---|---|---|
| link1 | (0, 0, 0.333) | **0.0000** | 不动 |
| link2 | (0, 0, 0.333) | **0.0000** | 不动 |
| link3 | (0, 0, 0.649) | **0.0000** | 不动 |
| link4 | (0.0825, 0, 0.649) | 0.0825 | **动** |
| link5 | (0, 0, 1.033) | **0.0000** | 不动 |
| link6 | (0, 0, 1.033) | **0.0000** | 不动 |
| link7 | (0.088, 0, 1.033) | 0.0880 | **动** |
| hand | (0.088, 0, 0.926) | 0.0880 | **动** |

**规律一目了然**：距离为 0 的不动，不为 0 的才扫出圆弧。

道理很简单：z 轴上的点旋转后还是它自己：

```
(0, 0, z) 绕着 z 轴转任意角度 → 还是 (0, 0, z)
```

**为什么要专门讲这个？** 因为这就是**奇异位形（singularity）**的起点。当末端正好落在某个关节的转轴上时，转那个关节对末端毫无影响——**那个方向上你失去了控制能力**。工业机械臂的很多控制难题都由此而来。

**那"子树"到底是什么意思？** 看这张树：

```
world
 └─ link0           ← 底座，joint1 的"上游"，不受影响
     └─ link1       ← joint1 长在这里
         └─ link2   ← 下游，会跟着转（但它的原点在轴上，所以位置不变）
             └─ link3
                 └─ link4
                     └─ link5
                         └─ link6
                             └─ link7
                                 └─ hand
                                     ├─ left_finger
                                     └─ right_finger
```

**joint1 下游的所有东西都在转**（包括 link2、link3 的姿态），只是它们的**原点**恰好在轴上，所以**位置**看不出变化。这提醒你一件事：

> **位置没变 ≠ 姿态没变。** `xpos` 和 `xmat` 是两个独立的量。

## 4. 实验 4：位移 ≈ 力臂 × 转角 ★ 全场最重要

### 答案：joint2

### 底层原理：从"力臂"到"雅可比"

先看这张表（转角固定为 0.3 rad）：

| 关节 | 末端到该转轴的垂直距离 r | 预测 r×0.3 | 实测位移 |
|---|---|---|---|
| joint1 | 0.0880 | 0.02640 | 0.02630 |
| **joint2** | **0.5995** | **0.17985** | **0.17917** |
| joint3 | 0.0880 | 0.02640 | 0.02630 |
| joint4 | 0.2771 | 0.08312 | 0.08281 |
| joint5 | 0.0880 | 0.02640 | 0.02630 |
| joint6 | 0.1385 | 0.04156 | 0.04141 |
| **joint7** | **0.0000** | **0.00000** | **0.00000** |

**规律简单到令人意外**：

> **末端移动的距离 ≈ （末端到该关节转轴的垂直距离 r）×（转角）**

这个 `r` 就是**力臂**——你在初中物理学的杠杆原理，在这里原封不动地复现了。

### 为什么预测和实测有微小差异

因为 `位移 = r × θ` 只在**角度很小时**严格成立。精确的公式是：

$$d = 2r\sin\left(\frac{\theta}{2}\right)$$

代入 `r = 0.088, θ = 0.3`：`2 × 0.088 × sin(0.15) = 0.02631`，和实测的 `0.02630` 几乎完全吻合。

（`r×θ` 是这个式子在小角度下的泰勒展开，误差是 θ³ 量级。`0.3³/24 ≈ 0.001`，正好解释了那一点点偏差。这就是工程上"小角度近似"的典型用法。）

### 从这里到雅可比

**雅可比矩阵**的定义是把末端位置对每个关节角求偏导：

$$J_{ij} = \frac{\partial p_i}{\partial q_j}$$

- `p` = 末端位置（3 维）
- `q` = 关节角（7 维）
- 所以 `J` 是一个 **3×7 的矩阵**

再看上面那张表：**"位移 / 转角" 就是导数 `∂p/∂q` 的数值近似。**

也就是说：

> **实验 4 那张表的每一行，就是雅可比矩阵的"大小"（每一列的模长）。**
> 你其实已经在用差分法算雅可比了，只是当时不知道那个名字。

雅可比为什么重要？因为速度关系是：

$$\dot{p} = J(q)\,\dot{q}$$

**"关节转多快" 乘以 "雅可比" = "末端动多快"。** 逆运动学（IK）、力控、奇异分析，全部建立在它上面。Step 3 你会把它推出来。

### joint7 的位移是 0，说明了什么

末端正好落在 joint7 的转轴上（`r = 0`）。转 joint7 只是让夹爪**原地自转**，末端点纹丝不动。

这是**奇异位形**最直观的一个例子。它对你有两个实际意义：

1. **在那个方向上你控制不了末端**——不管 joint7 转多快，末端都不会动
2. **雅可比矩阵在那一刻是奇异的**（行列式为零），求逆会爆炸。所以数值 IK 必须用**阻尼最小二乘（DLS）**而不是朴素求逆——这就是 Step 3 要处理的第一个工程问题

## 5. 实验 5：100 次 `mj_forward` 会改变 `qpos` 吗

### 答案：不会

### 底层原理：纯函数 vs 状态推进

这是第 1 课第 7 节的实验版本。

| | `mj_forward` | `mj_step` |
|---|---|---|
| 输入 | `qpos`, `qvel` | `qpos`, `qvel`, `ctrl` |
| 输出 | 写入所有派生量（`xpos`/`xmat`/力/接触） | 同上，**并且**更新 `qpos`/`qvel` |
| 会改状态吗 | ❌ 不会 | ✅ 会 |
| 会推进时间吗 | ❌ 不会 | ✅ 会（+ dt） |
| 数学性质 | **纯函数**（同样输入必得同样输出，无副作用） | 带状态转移 |

实验里同样跑 100 次：`mj_forward` 之后 `qpos` 纹丝不动；`mj_step` 之后关节角漂移了 **0.1956 弧度**（约 11°）——因为重力把手臂往下拽了，而位置伺服电机的目标位置还是 0。

### 为什么"纯函数"这个性质对你极其重要

写 FK/IK 验证代码时：

- 用 `mj_forward`：可以放心反复调用，状态永远干净，**数值可复现**
- 误用 `mj_step`：时间一直往前走，重力持续作用，机械臂慢慢下沉，**你的误差永远对不上，而且找不到原因**

这类 bug 特别难查，因为你的代码逻辑看上去完全正确。**记住：做运动学 → `mj_forward`；做动力学/控制 → `mj_step`。**

## 8. 小结

| 实验 | 一句话原理 | 通向哪里 |
|---|---|---|
| 1 | 关节角拼成 `qpos`，长度 = 自由度 | 广义坐标 |
